# NumPy, Pandas, Matplotlib & Seaborn Practice

This repository contains a collection of small exercises and practice notebooks that I completed while learning Python for data analysis and visualization.

The goal of this repository is to strengthen my understanding of the core Python libraries used in data science through hands-on practice.

## 📚 Libraries Covered

* **NumPy** – Array creation, indexing, reshaping, mathematical operations, and statistics.
* **Pandas** – DataFrames, data cleaning, filtering, grouping, merging.
* **Matplotlib** – Creating line charts, bar charts, histograms, scatter plots, pie charts, and customizing visualizations.
* **Seaborn** – Statistical visualizations including box plots, pair plots, violin plots, and distribution plots.
